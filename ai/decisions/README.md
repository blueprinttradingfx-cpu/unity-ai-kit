# Decisions (ADRs)

One file per decision: `NNNN-short-title.md`, copied from `0000-template.md`.
Write one when a choice is hard to reverse or shapes the code: UI technology, save format,
online backend, input scheme, tick rate, pipeline, major package, orientation, monetisation.

Rules for AI assistants:
- Read the index below before proposing architecture.
- Never contradict an accepted ADR silently. If it should change, write a new ADR that supersedes it.
- Propose an ADR (draft in chat) when you notice an unrecorded decision being made.
